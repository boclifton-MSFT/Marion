## Prerequisites

Install the .NET 10 SDK, the Aspire CLI, Node.js 22.19 or newer, and pnpm 11.

## Start the application

From the repository root:

```powershell [Terminal]
Set-Location src\Marion.Web
corepack pnpm install
Set-Location ..\..
aspire start
```

Aspire starts the API and Nuxt frontend and prints the authenticated dashboard URL.
