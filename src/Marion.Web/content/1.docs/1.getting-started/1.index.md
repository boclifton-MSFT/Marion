Marion is an AI-powered loan officer assistant for automating and understanding the loan origination workflow.

## Application architecture

- **Marion.AppHost** orchestrates the application with Aspire.
- **Marion.ApiService** provides the .NET backend.
- **Marion.ServiceDefaults** configures health checks, service discovery, resilience, and OpenTelemetry.
- **Marion.Web** provides the Nuxt user experience.

## Frontend foundations

The web application uses Nuxt, Nuxt UI, Nuxt Content, Vue 3, and TypeScript. Content in this directory is indexed for navigation and full-text search.
