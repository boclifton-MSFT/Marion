# Marion Web

The Marion web application is a Nuxt 4 frontend built with Nuxt UI and TypeScript. Aspire supplies its API endpoint and development port at runtime.

```powershell
corepack pnpm install
corepack pnpm dev
```

Use `corepack pnpm lint`, `corepack pnpm typecheck`, and `corepack pnpm build` before submitting frontend changes.
